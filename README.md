# Analysis of Bushfires in the Grampians Region

## Overview
This project conducts a comprehensive analysis of bushfire activity in the Grampians region, focusing on the Forest Fire Danger Index (FFDI) over the past 70 years. The study examines trends in bushfire danger, the impact of climate change, and the role of the El Niño Southern Oscillation (ENSO) on fire risk.

## Project Structure
- **data/**: Contains datasets used for the analysis.
- **scripts/**: R scripts for data analysis and visualization.
- **results/**: Visualizations and findings from the analysis.
- **README.md**: Project documentation.

## Background
Bushfires are a significant natural hazard in Australia, particularly in the Grampians region. This project aims to analyze FFDI trends, evaluate whether bushfire seasons are expanding, and assess the influence of ENSO events on fire danger ratings.

## Methodology
1. Data collection and preprocessing using R.
2. Analysis of FFDI trends across seasons and years.
3. Evaluation of ENSO impacts on bushfire occurrences.
4. Visualization of findings through graphs and plots.

## Key Findings
- Increasing trends in FFDI over the past decades.
- Evidence of expanding bushfire seasons.
- Correlation between ENSO phases and FFDI spikes.
